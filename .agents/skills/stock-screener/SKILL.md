# Stock Screener

機関投資家のアナリスト視点で、投資テーマや条件に合致する個別株候補を抽出し、ファンダメンタルズ・業界構造・バリュエーション・マクロ環境の4軸で横並び比較して有力銘柄を絞り込むスキル。

## When to Use

以下のいずれかに該当するリクエストで起動する。

- 特定のテーマ、セクター、市場（日本株・米国株）から投資候補の銘柄を探したいとき
- 投資スタイル（グロース、バリュー、高配当、ディフェンシブなど）や条件に合う銘柄をスクリーニングしたいとき
- 複数の候補銘柄や同業他社を横並びで比較し、どの会社が最も優位性が高いか選定したいとき

## Workflow

### 1. スクリーニング条件と投資スタイルの整理

ユーザーのリクエストから以下を整理する。未指定の項目は合理的な前提を置いて明示する。

- 対象市場（日本株 / 米国株 / グローバル）と対象セクター・テーマ
- 投資スタイル（グロース / バリュー / クオリティ / 高配当など）と重視する軸
- 除外条件（赤字企業を除く、時価総額の目安など）があれば反映

### 2. リアルタイム情報の取得（検索・データ取得必須）

記憶や古いデータに頼らず、必ずWeb検索またはデータ取得ツールを実行して最新の市場環境と候補企業（3〜5社）のデータを取得する。

- 対象テーマ・セクターにおける主要プレイヤーおよび直近で業績モメンタムが強い企業
- 各候補の最新株価、時価総額、直近決算の売上・営業利益成長率、ROE、営業CFの動向
- バリュエーション指標（予想PER、PBR、PSR、PEGレシオなど）と業界平均・過去水準
- セクターに影響を与えるマクロ環境（金利・為替・景気局面・規制や政策）

### 3. 4軸による企業分析と横並び比較

候補3〜5社を以下の4軸で冷静に比較・評価する。

1. **財務の質と稼ぐ力（決算書）**: 売上・営業利益の成長性、営業利益率、ROE、営業キャッシュフローの安定性、財務安全性（自己資本比率や有利子負債水準）。
2. **伸びる構造と競争優位性（業界・セグメント）**: どのセグメントが利益を牽引しているか。業界内の利益構造の違い、参入障壁（モート）、中期経営計画やシェア動向。
3. **株価の割安・割高評価（バリュエーション）**: PER・PBR（PBR = PER x ROE の分解）・PSR・PEGレシオを用い、「同業他社との比較」と「自社の過去レンジとの比較」の2軸で評価する。
4. **マクロ環境との適合性**: 現在の金利・為替・物価・景気局面が、そのセクターおよび各社のビジネスモデルにとって追い風か逆風か。

### 4. 出力フォーマットの遵守

以下の構成で構造化して出力する。参照した一次情報・ニュースの出典URLも明記する。

1. **スクリーニング条件とマクロ環境**: 選定条件の整理と、対象セクターに対する現在のマクロ環境評価（追い風・逆風要因）
2. **候補銘柄の横並び比較表**: 銘柄名（ティッカー）、主力セグメント・強み、成長性・ROE、バリュエーション（PER/PBR等）、主要リスクをまとめたMarkdownテーブル
3. **各社の簡潔な企業分析と選定結果**: 候補ごとの評価ポイント、落選・見送り理由、および最有力候補（1〜2社）の選定根拠
4. **次ステップへの連携（midterm-stock-planner用）**: 最有力候補について、そのまま中期シナリオ策定スキルへ引き継げるプロンプト例を提示する

## Gotchas

- **検索・データ確認の省略禁止**: 最新の業績・株価・バリュエーションを確認せずに銘柄を推奨・比較しない。確認できない数値は推測せず「確認不可」と明記する。
- **テーマ性だけの選定禁止**: 話題性やニュースだけで選ばず、必ず利益構造・キャッシュフロー・バリュエーションの裏付けを確認する。
- **役割分担の徹底**: 本スキルは「候補の抽出・横並び比較・絞り込み」を担う。選定後の2〜3年シナリオ策定や分割購入プランの作成は `midterm-stock-planner`、日々の買い時判定は `stock-risk-gatekeeper` に引き継ぐこと。
