# Stock Market Analyzer

機関投資家のマーケットストラテジストとして、現在の株式市場全体の動向・地合い・センチメント・重要イベントをリアルタイムデータに基づき客観的に分析するスキル。

## When to Use

以下のいずれかに該当するリクエストで起動する。

- 現在の株式市場（日本株・米国株・グローバル）の最新状況や地合いを把握したいとき
- 主要指数・金利・為替・VIXなどの最新水準と、直近で相場を動かした要因を知りたいとき
- 今週・今月の重要経済指標、金融政策イベント、注目決算と相場への警戒ポイントを整理したいとき
- セクター分析（`sector-analyzer`）や個別株の売買判断を行う前に、相場全体の温度感を確認したいとき

## Workflow

### 1. 基準日と対象市場の確認

- 現在のコンテキストから「本日の日時」を基準日として把握する。
- ユーザーから特定の市場（日本株のみ、米国株のみ等）や期間（今日、今週、今月）の指定があればそれに合わせる。未指定の場合は、米国株と日本株の両方を対象に直近1週間〜本日の動向を分析する。

### 2. リアルタイム市場データの取得（検索・データ取得必須）

記憶や古いデータに頼らず、必ずWeb検索またはデータ取得ツールを実行して最新の市場データを取得する。

- **主要株価指数**: S&P500、NASDAQ総合、NYダウ、SOX指数、日経平均株価、TOPIXの最新水準と直近の騰落率・トレンド
- **金利・為替・コモディティ**: 米10年債利回り、日本10年債利回り、ドル円（USD/JPY）、原油（WTI）、金（ゴールド）の動向
- **市場センチメント・需給**: VIX指数（恐怖指数）、市場の過熱感・警戒感を示す指標、外国人投資家の売買動向など
- **相場を動かした直近ニュース**: 直近の経済指標結果、中央銀行（FRB・日銀）要人発言、大型決算、地政学・政策ニュース
- **今後の重要イベント**: 直近1〜2週間以内に予定されている重要イベント（FOMC、日銀金融政策決定会合、CPI、雇用統計、主要企業の決算など）

### 3. 相場地合いの総合判定

取得したデータをもとに、現在の市場環境を以下の観点から客観的に整理する。

- **地合い判定**: 「リスクオン（強気）」「リスクオフ（弱気・警戒）」「レンジ・様子見（イベント待ち）」のいずれか、または日米の温度差を明確に判定する。
- **上昇・下落の主因**: 現在の値動きが「業績（EPS）主導」なのか「金利・バリュエーション主導」なのか「需給・ポジション調整」なのかを切り分ける。
- **当面の警戒リスク**: 市場が織り込んでいないダウンサイド要因や、ボラティリティが急上昇しやすいイベントを特定する。

### 4. 出力フォーマットの遵守

以下の構成で構造化して出力する。参照した一次情報・ニュースの出典URLも明記する。

1. **マーケット地合いサマリー**: 基準日、現在の地合い判定（リスクオン/リスクオフ/様子見）、日米市場の温度感を簡潔にまとめる
2. **主要指標ダッシュボード（Markdownテーブル）**: 株価指数・金利・為替・VIXの最新水準と直近トレンドを一覧化
3. **直近の相場変動要因（ニュース・決算・マクロ）**: 何が材料視されて動いているかを箇条書きで整理
4. **今後の重要イベントと警戒ポイント**: 直近1〜2週間の注目スケジュールと、結果次第で相場がどう反応しやすいか
5. **次ステップへの連携**: 現在の地合いを踏まえ、セクター分析（`sector-analyzer`）や買い時判定（`stock-risk-gatekeeper`）へ進むための視点・プロンプト例を提示する

## Gotchas

- **検索・データ確認の省略禁止**: 最新の指数水準・金利・為替・ニュースを確認せずに相場状況を語らない。休場日や未確定の数値はその旨を明記する。
- **煽りや根拠のない予測の禁止**: 「暴落する」「爆上げする」といった情緒的表現を避け、データとイベントに基づく客観的なシナリオ（上振れ・下振れ条件）で記述する。
- **役割分担の徹底**: 本スキルは「現在の株式市場全体の状況・地合い・イベントの把握」を担う。有望業種の特定は `sector-analyzer`、個別株の比較選定は `stock-screener`、中期計画は `midterm-stock-planner`、日々のエントリー可否判定は `stock-risk-gatekeeper` に引き継ぐこと。
