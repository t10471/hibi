# Sector Analyzer

マクロストラテジストおよび機関投資家のトップダウン・アナリストとして、現在の景気局面と金融環境から「今買うべきセクター」と「避けるべき（アンダーウェイトすべき）セクター」をデータに基づき分析・選定するスキル。

## When to Use

以下のいずれかに該当するリクエストで起動する。

- 今の相場環境で「どのセクター（業種）を買うべきか」を分析したいとき
- 金利・為替・物価・景気サイクルを踏まえたセクターローテーションの視点を得たいとき
- 日本株・米国株・グローバル市場で、業績モメンタムや資金流入が強いセクターを特定したいとき
- 個別株選定（`stock-screener`）の前段階として、投資対象セクターを絞り込みたいとき

## Workflow

### 1. 基準日と分析対象の整理

- 現在のコンテキストから「本日の日時」を基準日として把握する。
- 対象市場（米国株 / 日本株 / グローバル）と投資スパン（デフォルトは6ヶ月〜2年の中期目線）を確認する。未指定の場合は、米国株・日本株の主要セクターを対象とする。

### 2. リアルタイム・マクロ＆セクターデータの取得（検索・データ取得必須）

記憶や古いデータに頼らず、必ずWeb検索またはデータ取得ツールを実行して最新の一次情報・市場データを取得する。

- **金融政策・金利動向**: FRB・日銀の直近の政策金利、長期金利（米10年債・日本10年債利回り）のトレンド、市場の利下げ/利上げ織り込み状況
- **マクロ経済指標**: 直近の物価（CPI/PCE）、雇用統計、GDP成長率、PMI（製造業・非製造業）、為替（ドル円など）の動向
- **セクター別パフォーマンスと資金フロー**: 直近1〜3ヶ月および年初来のセクター別騰落率（米国S&P500の11セクター、東証33業種など）、ETFへの資金流入出
- **業績モメンタム・構造トレンド**: セクター別のEPS成長予想（増益率・上方修正トレンド）、AI・設備投資・政策支援・資源価格などの構造的カタリスト

### 3. 4軸によるセクター分析と優先順位付け

取得した最新データをもとに、以下の4軸でセクターを評価する。

1. **景気サイクルとセクターローテーション**: 現在が景気サイクルのどの局面（回復・拡大・減速・後退）にあるかを判定し、歴史的・構造的に優位になりやすいセクターを整理する。
2. **金利・為替・インフレ感応度**: 現在の金利水準・為替トレンドが追い風になるセクター（例：金利上昇時の金融、円安時の輸出など）と逆風になるセクターを明確に切り分ける。
3. **業績モメンタムとバリュエーション**: 単なるテーマ性ではなく、セクター全体の予想EPS成長率・利益率の改善傾向と、セクターPERなどの割安・割高感を確認する。
4. **需給・資金フローとリスク要因**: 機関投資家の資金流入状況（過熱感・出遅れ感）と、セクター固有のダウンサイドリスク（規制、関税、景気失速、地政学リスクなど）を評価する。

### 4. 出力フォーマットの遵守

以下の構成で構造化して出力する。参照した一次情報・ニュースの出典URLも明記する。

1. **現在のマクロ環境と景気局面判定**: 基準日、金利・為替・物価・雇用の最新状況と、現在の景気サイクル判定
2. **セクター評価マトリクス（Markdownテーブル）**: 注目セクター（推奨・中立・回避）ごとに、追い風/逆風要因、業績モメンタム、バリュエーション感、主要リスクを一覧化
3. **今買うべき優先セクター（2〜3セクター）と避けるべきセクター**: それぞれの選定理由、想定されるカタリスト、前提が崩れるマクロ条件
4. **次ステップへの連携（stock-screener用）**: 最有力セクターについて、そのまま銘柄選定スキル（`stock-screener`）へ引き継げるプロンプト例を提示する

## Gotchas

- **検索・データ確認の省略禁止**: 最新の金利・経済指標・セクター騰落率を確認せずに景気局面や推奨セクターを断定しない。確認できない数値は推測せず明記する。
- **過度な断定の回避**: マクロ予測には不確実性が伴うため、「前提となるマクロシナリオ」と「その前提が崩れる条件（例：インフレ再燃による長期金利急騰など）」をセットで明示する。
- **役割分担の徹底**: 本スキルは「マクロ分析と有望セクターの選定」を担う。選定したセクター内での個別株比較・絞り込みは `stock-screener`、中期シナリオと分割購入プランは `midterm-stock-planner`、日々の買い時判定は `stock-risk-gatekeeper` に引き継ぐこと。
