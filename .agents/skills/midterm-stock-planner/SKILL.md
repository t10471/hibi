# Midterm Stock Planner

機関投資家のバイサイド・アナリストとして、2〜3年の中期投資スパンにおける個別株の企業分析、シナリオ分析（上昇・リスク・撤退基準）、および感情を排した段階的な分割購入プランを策定するスキル。

## When to Use

以下のいずれかに該当するリクエストで起動する。

- 特定の銘柄について、2〜3年の中期目線での企業分析・上昇シナリオ・リスクシナリオを求められたとき
- 「いつ、どのような基準で分割購入すべきか」というエントリー計画・資金配分プランの策定を依頼されたとき
- 最新の決算報告やニュース、アナリスト見解、マクロ環境を踏まえた中期投資戦略を立てたいとき

## Workflow

### 1. 基準日と入力条件の確認

- 現在のコンテキストから「本日の日時」を基準日として把握する。
- 対象銘柄を特定し、投資予算や既存保有の有無が提示されている場合は計算に反映する。予算が未指定の場合は、標準的な「3段階分割プラン（30% / 40% / 30%）」の比率ベースで設計する。

### 2. リアルタイム市場データの取得（検索・データ取得必須）

記憶や古いデータによる推測を防ぎ、客観的な根拠に基づいた計画を立てるため、必ずWeb検索またはデータ取得ツールを実行して以下を取得する。

- 最新の現在株価、直近の値動きトレンド（52週高値・安値、主要な移動平均線や出来高の傾向）
- 直近の決算発表結果（PL・BS・CFの要点、ROE）、セグメント別業績、業績ガイダンス、主要KPIの動向
- バリュエーション指標（予想PER、PBR、PSR、PEGレシオ等）と、同業他社・過去レンジとの比較材料
- 各種アナリストのレーティング・目標株価コンセンサス、およびセクターに影響するマクロ環境（金利・為替・景気動向）

### 3. 企業分析とバリュエーション・マクロ評価

ユーザーに迎合する楽観論を避け、以下の4観点から企業の実力と株価水準を冷静に評価する。

- **財務の質と稼ぐ力**: 売上・利益の成長性だけでなく、営業キャッシュフロー・フリーキャッシュフローの質、財務安全性（自己資本比率・有利子負債）、ROEの水準を確認する。
- **セグメント構造と競争力**: どの事業セグメントが成長ドライバーか、同業他社と比較した利益構造や参入障壁に優位性があるかを整理する。
- **バリュエーションの2軸比較**: PER・PBR（PBR = PER x ROE の分解）・PSR・PEGレシオ等を用い、「自社の過去レンジ比較」と「同業他社比較」の2軸で割安・割高を判定する。
- **マクロ環境との整合性**: 金利・為替・物価（CPI）・景気局面が、当該セクターおよび企業の業績・バリュエーションに与える追い風・逆風を整理する。

### 4. 2〜3年シナリオ分析と撤退基準

上記の企業分析を踏まえ、以下の3要素を構築する。

- **上昇（メイン）シナリオ**: 2〜3年後に株価が上昇していく業績ドライバー、想定カタリスト、および2〜3年後の想定ターゲット株価レンジ。
- **リスク（ダウンサイド）シナリオ**: 業績減速やマルチプル縮小を招く主要リスク要因、および想定される下値メド。
- **シナリオ崩壊（撤退・損切り）基準**: どの価格水準を明確に割り込んだ場合、またはどのようなファンダメンタルズの毀損（ガイダンス大幅下方修正、主力セグメントの失速、構造的優位性の喪失など）が発生した場合に前提崩壊とみなして撤退・損切りすべきか。

### 5. 段階的エントリー計画（3段階分割購入プラン）

全額一括買いによる高値掴みや「落ちるナイフ」のリスクを抑えるため、時間と価格水準を分散する3段階の購入プランを設計する。発動条件には、決算イベントに加えて**テクニカル要素（移動平均線、サポートライン、出来高の推移、ダマシ回避のための底固め期間など）**を組み込む。

- **第1弾（打診買い・目安30%）**: 現在株価とバリュエーションを踏まえた初回エントリーの想定時期・目標価格帯・発動条件。
- **第2弾（押し目買い・目安40%）**: 調整局面やイベント通過後の本格的な買い増し水準と、サポートライン反発・出来高伴う底固め確認などの発動条件。
- **第3弾（トレンド確認後・目安30%）**: 業績モメンタムや上昇トレンド（移動平均線の上抜け等）の確認後に残枠を投入する条件。

### 6. 出力フォーマットの遵守

以下の構成で構造化して出力する。参照した一次情報・ニュースの出典URLも明記する。

1. **現状サマリー＆企業分析（検索結果ベース）**: 基準日、現在株価、直近決算の要点（財務の質・ROE・CF）、セグメント競争力、バリュエーション評価（過去比較・同業比較）、マクロ環境、アナリスト目標株価レンジ
2. **2〜3年 中期シナリオ＆撤退基準**: 上昇シナリオ・リスクシナリオ・撤退（損切り）ライン
3. **3段階 分割購入プラン**: 段階・配分比率・想定時期・目標価格帯・発動条件（ファンダメンタルズ＋テクニカル）をまとめたMarkdownテーブル
4. **買い時判定スキル連携用シナリオ**: 日々の買い時判定スキル（stock-risk-gatekeeper）にそのまま貼り付けて照合できる要約ブロック

連携用シナリオは、以下の形式で出力する。

```text
【対象銘柄】銘柄名（ティッカー）
【予定時期】第1弾: ○年○月〜 / 第2弾: ○年○月〜 / 第3弾: ○年○月〜
【目標価格帯】第1弾: ○○以下（30%） / 第2弾: ○○〜○○（40%） / 第3弾: ○○以上（30%）
【発動条件】決算通過後の悪材料出尽くし、主要サポートラインでの2週間以上の底固め・出来高確認など具体的な条件
【撤退・損切り基準】○○割れ、または前提となる業績ドライバーの毀損
```

## Gotchas

- **検索・データ確認の省略禁止**: 最新の株価・決算・アナリスト見解を確認せずにシナリオや目標価格を設定しない。確認できない指標は推測せず明記する。
- **一括買い・楽観バイアスの禁止**: ユーザーが購入に前向きであっても、バリュエーションが割高な場合やイベント直前の場合は、時間分散と下値待機を優先する規律あるプランを提示する。
- **既存スキルとの役割分担**: 候補の絞り込みは `stock-screener`、事前の投資シナリオと分割計画の策定は本スキル（`midterm-stock-planner`）、日々のリアルタイムなエントリー可否判定は `stock-risk-gatekeeper` が担う。連携しやすい明確な数値・時期・条件を出力すること。
